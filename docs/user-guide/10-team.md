# Team and agents

Add your staff as **agents** so they can answer chats. The number of agents depends on your package.

## Add an agent or a supervisor

1. **Team → Agents → Add agent**.
2. Full name, email (their login) and a password (at least 8 characters with letters and numbers) – or press **Generate**.
3. **Role**: *Agent* or *Supervisor (team lead)*. You can change it later with the pencil button.
4. Share the login details. The password is not shown again.

## Roles

| | Owner | Supervisor (team lead) | Agent |
| --- | --- | --- | --- |
| Chats | All | All (Inbox, Chat queue, assign and move chats) | Only their own |
| Orders | All | All – edit, status, invoice, delete | Only their own – edit, status, invoice, delete |
| CRM, contacts, notes, labels | All | All | Their own customers |
| Reports, Agent performance, Activity log | Yes | Yes | No |
| Agents | Add, edit, reset password, remove | See the team, set Online / Offline / Away | Team board |
| Products, bot, automation, marketing, channels, billing, company settings | Yes | No | No |

Per agent you can **edit the name**, **reset the password** (they are signed out everywhere) and **Remove access** (they can't log in, and their open chats go back to the queue). **Restore access** brings them back. Removed agents don't use a seat. When all seats are used, remove an agent or upgrade in Billing.

## What agents can do

- See and answer **only their own chats** (My chats), accept new chats, pass them on.
- See their customers' orders, notes and labels; create orders and bookings from chat.
- **Change their own orders**: status, edit, send invoice, delete. Every change and delete is written to the **Activity log** the owner sees.
- Pick the **Pipeline stage** of their customer in the chat.
- Switch **Online / Offline** in the top bar.
- Agents can't change settings, products, packages or billing, and can't see other agents' chats.

## How chats are shared

1. A customer who already has an agent goes back to **the same agent** (if online).
2. Otherwise the chat goes to the **online agent with the fewest open chats**.
3. If nobody is online, it waits in the **Chat queue** and is given out when an agent comes online.

**Accept new chats automatically** (Settings → Chat routing, **on** by default): the chat goes straight into the agent's chats – no Accept button. The agent can still **Pass on** or **Hand back** a chat.

When it is **off**, the agent sees "New chat for you" in a bar just above the message box and presses **Accept** (or **Pass on**). If they don't accept in time, the chat moves to the next online agent ("Move an un-accepted chat after", default 24 hours). Accepting sends nothing to the customer; the bot keeps helping until the agent switches it off for that chat.

## Team board

**Team → Team board** shows who is **Online** (gets new chats), **Offline** and **Away** (leave, day off), with each agent's active, waiting and assigned chats. **Drag an agent** to change their status, or **drag a customer** onto another agent to move the chat.

## Agent performance

**Team → Agent performance** (today, 7, 30 or 90 days):

- Team: agents online, chats assigned, waiting to accept, team messages, orders for agents.
- Per agent: accepted chats, time to accept, reply time, customers answered, messages sent, notes written, unread now, waiting/open now, bot replies in their chats, chats → sale, orders, order value and bookings.

Orders made by the bot count for the agent who holds the customer.

## Activity log

**Team → Activity log** (owner and supervisors) shows who did what, newest first:

- **Deleted orders** – with the customer, phone, address, items and total, so nothing is lost.
- **Edited orders** – each changed field, old → new.
- **Order status** and **Order notes**.
- **Pipeline stage** changes made by hand.
- **Team roles** – an agent made supervisor or back.

Filter by type with the buttons on top; 50 entries per page.
